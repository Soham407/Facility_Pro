# Web Archive

This folder stores historical web-app documentation that should not be treated as current product truth.

Use this folder for:

- completed implementation campaigns
- superseded plans
- old audits
- demo-cycle notes and blockers
- prompt packs and one-off execution guides

If an archived document disagrees with [root `STATUS.md`](../../../STATUS.md), [root `CONTEXT.md`](../../../CONTEXT.md), or an active doc under `docs/product/`, `docs/planning/`, or `docs/demo/`, prefer the active/current-state document.

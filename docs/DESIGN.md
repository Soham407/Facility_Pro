# Design System: Impeccable Raw

This project uses a deliberately sharp, industrial, and highly functional design identity. We reject "vibe-coded" SaaS defaults (glassmorphism, gradient meshes, indigo/violet dominance, 8px border radii).

## Tokens

1. **Neutral Scale**: Tinted slightly cool/industrial (slate), heavily leaning into stark black-and-white contrast.
2. **Radius Stance**: Brutalist/Sharp (`0px` radius). Everything is a strict rectangle, enforcing a technical, engineered feel.
3. **Type Pairing**: Strict system default monospace for data and small labels, paired with a geometric sans-serif for headings (if available, otherwise clean system-ui).
4. **Saturated Accent**: Pure Vermilion/Orange (`24 100% 50%`). Used sparingly but decisively for primary actions and active states. No indigo, no violet.
5. **Signature Token**: The "1px Hard Blueprint Line" (borders everywhere, high contrast dividers, completely flat surfaces without drop shadows).

## Absolute Bans
- No glassmorphism (`backdrop-blur` used decoratively).
- No gradient text or gradient borders.
- No nested cards.
- No drop shadows or "glow" effects.
- No em dashes in copy.
- No buzzwords ("elevate", "supercharge", "seamless").
